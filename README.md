# Sistem Manajemen Produksi

## Deskripsi Sistem
Sistem Manajemen Produksi adalah aplikasi yang digunakan untuk membantu proses pengelolaan produksi pada perusahaan/manufaktur. Sistem ini membantu leader dan operator dalam mencatat data produksi secara lebih cepat, terstruktur, dan otomatis.

Sistem dapat digunakan untuk:
- Mengelola data operator
- Mengatur mesin produksi
- Mencatat hasil produksi
- Memantau target dan pencapaian produksi
- Menampilkan grafik produksi

---

## Fitur Sistem

### 1. Mengelola Produksi
Leader dapat:
- memilih operator untuk setiap mesin,
- membuat detail produksi,
- menginput jumlah actual produksi per jam.

Sistem akan:
- menyimpan data ke database,
- memperbarui grafik pencapaian produksi otomatis.

---

### 2. Manajemen Data
Sistem menyediakan pengelolaan data:
- operator,
- mesin,
- barang produksi,
- jadwal produksi.

---

### 3. Monitoring Produksi
Sistem menampilkan:
- data hasil produksi,
- target produksi,
- progress produksi,
- grafik pencapaian.

---

## Tujuan Sistem
Tujuan dibuatnya sistem ini adalah:
- mempermudah proses pencatatan produksi,
- mengurangi kesalahan input data,
- mempercepat monitoring produksi,
- membantu pengambilan keputusan produksi.
